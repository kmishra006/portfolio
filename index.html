Fitness Web App Overview

This web app allows users to track their fitness goals, calculate BMI, view class schedules, and book gym sessions. The backend is built using Flask, MySQL, and PHP to handle user data, while the frontend utilizes HTML, CSS, and JavaScript for an interactive experience.

  • Features include user registration, class booking, and fitness tracking.
  • The app integrates a BMI calculator that provides personalized health insights.
  • Users can log workouts and track personal records.
